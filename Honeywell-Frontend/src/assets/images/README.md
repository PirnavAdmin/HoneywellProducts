# Authorized image replacement area

The Phase 1 prototype stores its professional placeholder photography locally so catalogue cards do not depend on third-party hotlinks. The files in `catalog/` were selected from free-to-use Unsplash and Pexels photography and are mapped centrally in `src/data/imageLibrary.js`.

Replace these placeholders with client-approved product, project, category, or application assets when supplied. Keep the existing filenames or update the centralized map so components remain independent of the media source.

Source collections:

- Unsplash: security camera, network equipment, architecture, workplace, retail, logistics, industrial, healthcare, hospitality, education, agriculture, and construction photography.
- Pexels: surveillance cameras, solar-powered surveillance, and related security technology photography.
